# Secure Password Manager

## Project Overview

This project is a Secure Password Manager developed using Python, Flask, SQLite, and Cryptography. It allows users to securely register, log in, generate strong passwords, and store website credentials in an encrypted database.

## Features

- User Registration
- User Login
- User Logout
- Password Hashing
- Password Encryption
- Password Generator
- Add Password
- View Saved Passwords
- Delete Password
- SQLite Database
- CSRF Protection

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- Flask-WTF
- SQLite
- Cryptography
- Bootstrap 5

## Installation

1. Install the required packages:

```bash
pip install -r requirements.txt
```

2. Run the application:

```bash
python app.py
```

3. Open your browser and visit:

```
http://127.0.0.1:5000
```
